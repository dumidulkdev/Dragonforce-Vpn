Hybrid routing

System proxy or full TUN — your choice

Use Windows system proxy for browsers and proxy-aware apps, or switch to Wintun with tun2socks when you need broader coverage for games, terminals, and non-proxy software. The client bundles Xray, tun2socks, and Wintun binaries for a single install flow.

  • Local SOCKS and HTTP inbound ports (configurable)
  • One-click terminal HTTP_PROXY / ALL_PROXY environment setup
  • Admin relaunch path for TUN mode on Windows
  • LAN bypass and TLS certificate pinning options
